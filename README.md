# おくすり なにに混ぜる？

子どもの粉薬の味、アイスやジュースに混ぜていいか、飲ませ方のコツが、薬の名前を選ぶだけで分かるスマホ用のページです。飲めたら「のめた！」スタンプを押せます（デモ版）。

小児科の門前薬局で、保護者から一番よく聞かれる「この薬、何に混ぜていい？」「アイスと一緒でいい？」に、家でもすぐ答えが分かるようにするために作っています。作っているのは、子育て中の薬剤師です。

## 使い方

1. `index.html` をスマホのブラウザで開く
2. 薬の名前を選ぶ（ひらがなでも探せます）
3. 「メーカーのおすすめ」「混ぜてだいじょうぶ」「苦くなりやすい」「効き目に影響することがある」に分かれて食べ物が出ます
4. 下の「飲ませ方のコツ」で、練ってほっぺの内側にぬる、スポイト、服薬ゼリーなどの方法を見られます
5. 飲めたら「のめた！ スタンプをおす」。スタンプ帳に日付と時間が残ります（記録はそのスマホの中だけに保存）

URL の最後に薬の名前が入るので、そのまま LINE で家族に送れます。

## データの出どころ

- 薬と食べ物の相性: 「散剤と飲食物の飲み合わせ（味）一覧」2016年7月改訂（[PDF](https://aih-net.com/yakuzaibu/kusurinomame/pdf/tekihihtou.pdf)）から、小児科でよく出る 25種類を選んで使っています。詳しくは [docs/07_demo_data.md](docs/07_demo_data.md)
- どの薬にも共通の注意: [PMDA くすりQ&A](https://www.pmda.go.jp/safety/consultation-for-patients/on-drugs/qa/0008.html)
- 飲ませ方のコツ: 千葉県こども病院、マイナビニュース、熊本 くすりの話、PMDA、龍角散の商品説明、診断と治療社（各項目に出どころを表示）

## 注意

- このページは、薬の量、薬どうしの飲み合わせ、薬をやめるかどうかは判断しません。迷ったときは、薬をもらった薬局か医師に聞いてください
- データは 2016年の資料をもとにしているため、今の製品と違う場合があります
