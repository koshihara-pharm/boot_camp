# こどもおくすりサポート

子どもが少しでも薬を飲めるように、親を手伝うスマホ用の Web サイトです（デモ版。名前は仮）。

作っているのは、小児科の門前薬局で働く、子育て中の薬剤師です。窓口で一番よく聞かれる「この薬、何に混ぜていい？」「アイスと一緒でいい？」に家でも答えが分かり、飲めたら子どもがスタンプで喜べるようにしています。

## できること

1. **薬の味**: 薬を選ぶと、一番上に味とにおいが出ます
2. **家にある食べ物と混ぜていいか**: アイス、プリン、ジュースなど 12 の食べ物を「メーカーのおすすめ」「混ぜてだいじょうぶ」「資料によって評価が分かれる」「苦くなりやすい」「効き目に影響することがある」に分けて表示します
3. **飲ませ方のコツ**: 練ってほっぺの内側にぬる、スポイト、味の濃いものに混ぜる、服薬ゼリーで包む、など（各項目に出どころ）
4. **おくすり記録 → 家族や保育園に伝える**: いま飲んでいる薬（飲む時間、1回の量、何日分）を薬袋のとおりに入れると、
   - 家族向け: きょう飲めた時間と、混ぜていい／混ぜないほうがいい食べ物をまとめたメモを LINE で送れます
   - 保育園向け: 与薬依頼書に書き写すためのメモ（薬の名前、1回の量、昼、期間、医療機関）を作ります
5. **「のめた！」スタンプ**: 押すと大きなスタンプが出てほめてくれます。スタンプ帳に日ごとに残り、決められた日数を最後まで飲みきると「さいごまで のめたね！」

記録（いま飲んでいる薬、スタンプ）は、そのスマホのブラウザの中だけに保存します。サーバーには送りません。送るかどうかは親が決めます。

## 使い方

`index.html` をスマホのブラウザで開きます（`data.js` と同じ場所に置く）。

## データの出どころ

- 薬と食べ物の相性、薬の味: 「散剤と飲食物の飲み合わせ（味）一覧」2016年7月改訂（[PDF](https://aih-net.com/yakuzaibu/kusurinomame/pdf/tekihihtou.pdf)）から、小児科でよく出る 25 種類を選んで使っています。詳しくは [docs/07_demo_data.md](docs/07_demo_data.md)
- どの薬にも共通の注意: [PMDA くすりQ&A](https://www.pmda.go.jp/safety/consultation-for-patients/on-drugs/qa/0008.html)
- 飲ませ方のコツ: 千葉県こども病院、マイナビニュース、熊本 くすりの話、PMDA、龍角散の商品説明、診断と治療社（各項目に出どころを表示）

## 注意

- このサイトは、薬の量、薬どうしの飲み合わせ、薬をやめるかどうかは判断しません。量や回数は薬袋のとおりに親が入力します。迷ったときは、薬をもらった薬局か医師に聞いてください
- 混ぜていいかのデータは 2016 年の資料をもとにしているため、今の製品と違う場合があります
