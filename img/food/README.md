# 食べ物・飲み物のアイコン（img/food）

Fluent Emoji（img/fluent）に合う絵が無い食べ物の、アイコンの絵。Codex（ChatGPT の画像づくり、image_gen）で作った（2026-11-11 ユーザーの指示）。最初はモビコールの飲み物の例のため。

- どの食べ物にどの絵を出すかは、data.js の FOOD_IMG（食べ物の名前 → ファイルの名前）
- 画風: Fluent Emoji の Flat に近い、平らでシンプルな絵。背景は透明。文字は入れない。正方形の真ん中に1つだけ大きく描く
- 大きさ: 192 × 192 の PNG。画面では 26px で出すので、小さくしても見分けられることをいちばん大事にする
- 入れ物（ボトル・カップ・湯のみ）は真っ白にしない。白い地の上で形が消えるため（1回目に、白い入れ物で作って消えた）。おわんは、みそ汁＝外が黒・内が赤、お吸い物＝全体が赤、で分ける
- 今ある絵: nomu-yogurt（飲むヨーグルト）、corn-soup（コーンスープ）、miso-soup（みそ汁）、osuimono（お吸い物）、kobucha（昆布茶）
- 足すとき: Codex に、上の画風と、となりに並ぶ絵（Fluent Emoji）のことを伝えて作り、ここに入れて、data.js の FOOD_IMG に足す
