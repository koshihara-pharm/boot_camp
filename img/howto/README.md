# 飲ませ方の絵（img/howto）

飲ませ方のやり方を開いたときに、手順の上に出す絵。Codex（ChatGPT の画像づくり、image_gen）で作った（2026-11-10 ユーザーの指示）。

- 名前は data.js の METHODS の名前と同じ（例: water.webp ＝ 少しの水で溶かす）
- 画風: 平らでシンプルな絵、白い背景、やわらかいオレンジとうすい水色。大人は手と腕だけ。絵の中に文字は入れない
- 横 800 × 縦 600 の webp にして入れる
- 薬の袋は、日本の薬局の分包にならって、ほぼ正方形にする。スポイトは、注射器の形ではなく、先が細く、端に丸いふくらみがある形にする（2026-11-10 ユーザーの指示）
- icon_*.webp は、やり方の見出しの左に出すアイコンの絵（192 × 192）。手は入れず、やり方の道具を1つだけ大きく描き、7つで目立つ色を分ける。小さくしても見分けられることをいちばん大事にする（2026-11-10 ユーザー「差分が少なく分かりにくい」）
