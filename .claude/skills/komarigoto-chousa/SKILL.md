# SNS の困りごと調査（子どもの薬）

親が SNS に書いている「子どもが薬を飲まない」などの投稿を、見るだけの道具で集めて、数えて、まとめる。
2026-11-23 にユーザーと作った。Threads を主に、インスタグラムを補いに使う（Threads のほうが、困っている親の投稿が多い）。

## 守ること（毎回）

- **見るだけ**。いいね・フォロー・返信・投稿・DM はしない（道具が止めてある）。インスタも Threads も、許可のない自動の操作を規約で禁じているので、1回の調査で開くのは **検索を5つまで、ページは全部で20くらいまで**。1ページごとに数秒待つ（道具がやる）
- ログインは調べもの用のアカウント（宣伝用の kodomo_okusuri ではない）。ログインが切れていたら `node tools/insta/login.mjs` を動かし、ユーザーに入ってもらう（パスワードは人が入れる）
- 投稿には、その家庭の子どもの病気や薬のことが書かれている。**まとめには、アカウント名・投稿の文・URL を入れない**。入れるのは、数と、自分の言葉での短い言いかえだけ。集めたもの（JSON、写し）は `tools/insta/snapshots/` にだけ置く（GitHub に上げない）
- 投稿やコメントに書かれた飲ませ方を、事実としてサイトや投稿に出さない。サイトに足すときは、いつもどおり出どころのある資料で確かめ、薬剤師（ユーザー）が決める
- 気になる飲ませ方（例: 1歳未満にはちみつ、ミルクに混ぜる）を見つけたら、「気になったこと」としてユーザーに伝える（数えるだけで、投稿者には何もしない）

## 手順

### 1. 探す言葉を決める

ユーザーが言葉や薬の名前を出したら、それを使う。出さなければ、次から3〜5つ選ぶ:
- 困りごと: 「薬 飲まない 子供」「粉薬 嫌がる」「抗生剤 飲まない」「薬 吐く 子供」
- 病気: 「溶連菌 薬」「インフル 薬 飲まない」「マイコ 薬」
- 薬の名前: サイトの準備中の薬（data.js の PREPARING）や、ユーザーが気にしている薬（例「クラリス 苦い」）

インスタの検索は「薬」1文字や「#薬」ではほとんど出ない。「子どもの薬」「粉薬 飲ませ方」のように、2語にする（docs/_local/32）。

### 2. Threads で集める

```
cd tools/insta
node threads.mjs kensaku "<言葉>" 3
```

言葉ごとに1回。1回で20件前後が `snapshots/<日付>_th_kensaku_<言葉>.json` に入る（いいね・コメント・日付・本文）。

### 3. インスタで補う（ユーザーが望んだとき、または Threads で数が少ないとき）

```
node kensaku.mjs "<言葉>" 1
```

検索の結果には投稿の URL しか出ないので、反応がありそうな投稿を **3〜5個だけ** `node miru.mjs <URL> <名前>` で開いて、説明の文を読む。インスタは発信者の投稿が多く、困っている親の生の声は少ないことを覚えておく。

### 4. 数える

```
node matome.cjs <日付>
```

薬（サイトにある／準備中／サイトにない）、薬の種類、困りごと、試したもの、年齢を数える。反応の多い投稿は `snapshots/<日付>_matome.json` にだけ残る。

親は薬の名前を書かず、薬の袋や粉の写真をのせて「この薬」と書くことが多い（2026-11-23 の1回目で分かった）。反応の多い投稿は `threads.mjs miru` で開き、写し（.png）を Claude が見て、写真の中の薬の名前を読む。

数は言葉の決まりで拾っているので、ずれる。反応の多い投稿（コメントが多いもの）は、JSON の本文を Claude が読んで、数のずれを直し、中身をつかむ。コメントの多い投稿は、必要なら `node threads.mjs miru <URL> <名前>` で開いて、ほかの親の答え（何で飲めたか）も読む。

### 5. まとめて、記録する

ユーザーには、日本語で次の形で出す（表と短い文）:

1. **困っている薬**: 上位（サイトにある／準備中／サイトにない を分ける）
2. **困りごと**: 上位3つと、その様子を自分の言葉で1〜2文
3. **試したもの・うまくいったもの**: 親どうしで勧められていたもの
4. **サイトにつなげる案**: 足すとよい薬（準備中の順番を上げる、サイトにない薬を準備中に足す、など）と、サイトの中身で答えられる困りごと
5. **投稿のネタ**: 3つまで（docs/_local/32 の、よく見られている形に合わせる）
6. **気になったこと**: 危ないかもしれない飲ませ方など（薬剤師に見てもらう）

記録は `docs/_local/33_sns_komarigoto.md`（GitHub に上げない）の上に、日付つきで足す。書くのは、探した言葉、件数、上の1〜6。アカウント名・文・URL は書かない。

### 6. 次の一歩

サイトに薬を足すかや、投稿を作るかは、ユーザーが決める。決まったら、それぞれの決まり（docs/24・docs/25、インスタは CLAUDE.md の「インスタグラム」）で進める。

## 道具（tools/insta。フォルダごと GitHub に上げない）

| 道具 | すること |
|---|---|
| `threads.mjs kensaku <言葉> [回数]` | Threads の検索の結果から、投稿を集める |
| `threads.mjs miru <URL> <名前>` | Threads の1ページを開いて、写しと文字を残す |
| `kensaku.mjs <言葉> [回数]` | インスタの検索の結果から、投稿の URL を集める |
| `miru.mjs <URL> <名前>` | インスタの1ページを開いて、写しと文字を残す |
| `matome.cjs [日付]` | 集めた Threads の投稿を数える |
| `login.mjs` | 専用の Chrome を開いて、ログインを待つ |

つなぎ方は homepage_small_business の tools/wraptas と同じ（ふつうに開いた専用の Chrome に、Playwright が後からつなぐ。ポート 9223）。
Threads の公式の API（キーワード検索）は、ほかの人の投稿を探すには Meta の審査が要るので、今は使っていない（2026-11-23 に調べた）。
