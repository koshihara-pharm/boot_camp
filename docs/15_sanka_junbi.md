## Slack の名前

- Full name（氏名）: ローマ字の本名 例 `Yamada Taro`
- Display name（表示名）: 漢字の本名 例 `山田 太郎`
- 本名・旧姓の本名・通名のどれか。ニックネームは禁止

## Slack のルールの要点

- 自己紹介は canvas で（うまく使えなければ普通の投稿）。タイトルに「自己紹介」
- **毎日 Slack を見る**。参加しているチャンネルは全部目を通す
- 質問・依頼には **12時間以内に反応する**（「今できないので3日後にやります」でもよい）
- DM、全体メンション（@all、@channel、@here）、Slack Connect は原則禁止
- スレッドの「チャンネルにも投稿する」は禁止。スレッドは個別の話だけ。基本はチャンネルに書く
- 1つの投稿に1つの話題。依頼には「何を・だれが・いつまでに（JST）」を書く
- あいさつは短く、必要なことだけ。雑談や素朴な質問は歓迎
- ROM（見るだけ）やスタンプを押すだけにならない
- **公開チャンネルは、あとから入った人もずっと読める**。玄関に貼り出して困らない内容だけ書く

このプロジェクトとしての注意（CLAUDE.md の「守ること」と同じ）:
- 子どもや家族の本名、生年月日、病名、処方内容、病院名は書かない
- 勤め先の薬局の名前や患者さんのことは書かない
- 他の参加者の情報を外に出さない

## 自己紹介の下書き（Slack の canvas 用）

Claude が下書きしたもの。投稿する前に、ユーザーが自分の言葉に直す。【 】はユーザーが埋める。

```
自己紹介：【名前】

■ どんな人か
薬剤師です。子育て中で、副業で小児科の門前薬局でも働いています。
薬局向けのホームページ・採用ページ・公式 LINE の構築を、Notion・Wraptas・Claude Code で副業として始めています（エンジニアではありません）。

■ 持ち込むプロジェクト：こどもおくすりサポート
子どもが少しでも薬を飲めるように、親を手伝うスマホ用の Web サイトです（のちにアプリ）。
窓口で一番よく聞かれる「この粉薬、何に混ぜていい？」「どうしても飲んでくれない」に、家でスマホから答えが分かるようにしています。

・公開 URL：https://koshihara-pharm.github.io/boot_camp/
・GitHub：https://github.com/koshihara-pharm/boot_camp

いまできること
1. 薬の味とにおい
2. 家にある12の食べ物（アイス、プリン、ジュースなど）と混ぜていいか（出どころの資料名・年つき）
3. 飲ませ方のコツ（出どころつき）
4. いま飲んでいる薬の記録 → 家族に LINE で送るメモ、保育園の与薬依頼書に書き写すメモ
5. 「のめた！」スタンプ。最後まで飲みきったらごほうび

大事にしていること
・医療上の判断はしない（量・中止・薬どうしの飲み合わせは出さず、医師・薬剤師に聞く導線にする）
・混ぜていいかは、出どころのある資料の内容だけを出す。中身は薬剤師の私が確認する
・子どもの記録はスマホの中だけに保存し、サーバーに送らない

■ これまで作ったもの
・薬局向け Web 制作のサービス紹介サイト：https://sumobiji-ph.jp/

■ 期間中にやりたいこと
・対応する薬と資料を増やす
・飲ませ方を絵や短い動画で分かるようにする
・知り合いの親に毎週使ってもらい、困ったことを聞いて直す
・マネタイズの形を決める

■ 貢献できること
・薬・医療まわりのプロダクトの確認（薬剤師の目線。もちろん一般的な範囲で）
・非エンジニアが Claude Code で作って公開するまでの進め方の共有
・Notion + Wraptas でのサイト制作
・子育て中の親としてのフィードバック

■ 相談したいこと
・親向けサービスのマネタイズ
・アプリ（iPhone / Android）にするときの技術の選び方
・最初の利用者の集め方

■ 連絡
Slack は毎日見ます。【返事しやすい時間帯があれば】
```

投稿前の確認:
- [ ] 名前を入れる
- [ ] 子どもの月齢（「生後1か月」など）を書くかどうか。下書きには入れていない
- [ ] 公開 URL が開けることを確かめる
- [ ] 自分の言葉に直す

  - https://github.com/koshihara-pharm/boot_camp
