## Slack の名前

- Full name（氏名）: ローマ字の本名 例 `Yamada Taro`
- Display name（表示名）: 漢字の本名 例 `山田 太郎`
- 本名・旧姓の本名・通名のどれか。ニックネームは禁止

## Slack のルールの要点

全体の要約は [docs/16](16_slack_rule.md)。

- 自己紹介は canvas で（うまく使えなければ普通の投稿）。タイトルに「自己紹介」
- **毎日 Slack を見る**。参加しているチャンネルは全部目を通す
- 質問・依頼には **12時間以内に反応する**（「今できないので3日後にやります」でもよい）
- DM、全体メンション（@all、@channel、@here）、Slack Connect は原則禁止
- スレッドの「チャンネルにも投稿する」は禁止。スレッドは個別の話だけ。基本はチャンネルに書く
- 1つの投稿に1つの話題。依頼には「何を・だれが・いつまでに（JST）」を書く
- あいさつは短く、必要なことだけ。雑談や素朴な質問は歓迎
- ROM（見るだけ）やスタンプを押すだけにならない
- **公開チャンネルは、あとから入った人もずっと読める**。玄関に貼り出して困らない内容だけ書く

このプロジェクトとしての注意（CLAUDE.md の「守ること」と同じ）:
- 子どもや家族の本名、生年月日、病名、処方内容、病院名は書かない
- 勤め先の薬局の名前や患者さんのことは書かない
- 他の参加者の情報を外に出さない

```
はじめまして、【名前】と申します。
薬剤師をしています。子育て中で、副業で小児科の門前薬局でも働いています。
もともと IT には興味があり、薬局向けのホームページ・採用ページ・公式 LINE の構築を、Notion・Wraptas・Claude Code を使って副業として始めました。本格的なプログラミングの経験はありませんが、生成 AI のおかげで、現場で感じている困りごとを自分の手で形にできるようになったことに面白さを感じています。

■ 今作っているもの
① こどもおくすりサポート（BootCamp で取り組むプロジェクト）
子どもが少しでも薬を飲めるように、親を手伝うスマホ用の Web サイトです（のちにアプリにしたいと考えています）。
薬局の窓口で一番よく聞かれるのが「この粉薬、何に混ぜていい？」「アイスと一緒でいい？」「どうしても飲んでくれない」です。混ぜていいかは薬ごとに違い、病院が出している表はあるのですが、子どもを抱えた親が家でスマホから調べられる形にはなっていません。
今できるのは、薬の味、家にある食べ物と混ぜていいか（出どころの資料名・年つき）、飲ませ方のコツ、飲んでいる薬を家族や保育園に伝えるメモ、「のめた！」スタンプです。
量や中止などの医療上の判断はせず医師・薬剤師に聞く導線にすること、子どもの記録はスマホの中だけに保存することを大事にしています。
公開サイト：https://koshihara-pharm.github.io/boot_camp/

② 薬局向けのホームページ・公式 LINE 構築（副業）
公開サイト：https://sumobiji-ph.jp/

■ この BootCamp で取り組みたいこと
特に取り組みたいのは次の3つです。

1. 使ってもらいながら直す：知り合いの親に毎週使ってもらい、「今週困ったこと」を聞いて改善したい。自分も子育て中なので、一番のユーザーとして使い込みたい
2. 安心して使える作り：薬の情報を扱うので、出どころの示し方や、個人情報をサーバーに送らない作りなど、安心して使ってもらえる設計を学びたい
3. 続けられる形にする：マネタイズやアプリ化（iPhone / Android）の進め方を、経験のある方に相談しながら考えたい

■ 目指していること
薬が苦手な子どもは多いのに、エンジニアや企業があまり手をつけていない領域だと感じています。
毎回の服薬が親子にとって少しでも楽になり、飲めずに余ってしまう薬が減るサービスにしたいです。

■ 貢献できること
薬剤師として、薬や医療まわりのプロダクトについて、一般的な範囲で気づいたことをお伝えできます。
また、非エンジニアが Claude Code で作って公開するまでの進め方や、Notion + Wraptas でのサイト制作の経験も共有できます。子育て中の親の目線でのフィードバックもできればと思います。
皆さんと交流しながら、いろいろなことに挑戦できる半年間にしたいです。
どうぞよろしくお願いいたします！
```
