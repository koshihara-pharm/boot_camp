# 小児の薬のニーズと、お金の流れ

- 作成: 2026-10-10
- 目的: 市場のニーズに合い、マネタイズできる方向を選ぶための材料
- 前提: ユーザーは子育て中の薬剤師で、副業で小児科門前の薬局に勤めている。親としても薬剤師としても、自分で使える（ドッグフーディングできる）立場
- 「確認済み」は出どころのある情報。「未確認」はまだ調べきれていない、または推測のこと

## 1. 誰が、何に困っているか

### 親（ママ・パパ）
- 確認済み: 子どもに薬を飲ませるのに苦労した保護者は約72%。一番大変なのは1〜3歳、薬の形では粉薬（docs/03）
- 確認済み: 小児科中心の薬局には、保護者から毎日のように「熱があるが、熱さましを飲ませていいか」という問い合わせがある（[薬事日報 2009](https://www.yakuji.co.jp/entry16698.html)。古い記事）
- 確認済み: 育児中の母親の約60%は、薬剤師に相談したことがない（[2015年の論文](https://jlc.jst.go.jp/DN/JLC/20016227420?from=WPRIM)）
- 確認済み: 小児の夜間・休日の時間外受診は増えていて、多くは軽症。薬剤師が相談に乗る取り組みをしている県もある（[薬事日報 2008](https://www.yakuji.co.jp/entry6138.html)。古い記事）
- 確認済み: 発熱の経過を受診のときに正確に伝えにくい、という問題を扱った研究がある（[情報処理学会](https://ipsj.ixsq.nii.ac.jp/record/110107/files/IPSJ-Z74-6V-3.pdf)）

### 薬局
- 確認済み: 2020年の改正薬機法で、薬を渡したあとも、飲んでいる期間中の患者フォロー（服薬フォローアップ）が薬剤師の義務になった（[薬事日報](https://www.yakuji.co.jp/entry81326.html)）
- 確認済み: 電話でのフォローは難しい、という懸念が当初からある（同上）
- 確認済み: 乳幼児服薬指導加算（6歳未満、12点）と、医療的ケア児が対象の小児特定加算（350点）がある（[日本薬剤師会の資料 2023年1月版](https://www.nichiyaku.or.jp/files/co/pharmacy-info/2023/01.pdf)）
- 未確認: 2024年改定のあとの点数と要件。厚労省の告示・通知の原文で確かめる

### 保育園
- 確認済み: 与薬依頼書は書く項目が多く、薬が変わるたびに書き直し（docs/03）
- 未確認: 連絡帳アプリ（コドモンなど）に与薬依頼の機能があるか。ストアの説明文では見当たらなかった（[コドモン](https://apps.apple.com/jp/app/id1005539404)）

## 3. マネタイズの道筋（3案）

### 案1: 薬局向け「小児の服薬フォロー」（B2B2C）
- 中身: 薬局が親の LINE に「お薬飲めましたか？」「吐いてしまった？」を送り、困っている家庭を薬局に知らせる。質問と案内文は小児用に作り込む（粉薬が飲めない、吐いた、熱さましの使い方の確認）
- 払う人: 薬局（月額）。親は無料
- 強み: フォローアップは法律上の義務。電話の問い合わせが減れば、薬局の手間も減る。小児科門前の現場を知る薬剤師が作る、という差別化
- 弱み: 大手（Pocket Musubi など）と重なる。患者情報を扱うので、本格運用では医療情報の安全管理ガイドラインへの対応が必要。営業の手間がかかる

### 案2: 親向け「家族で共有する、子どもの薬の記録」（B2C）
- 中身: 誰が、いつ、何を飲ませたかを夫婦で共有する。熱さましの前回の時刻が分かる。受診のときに経過を見せられる
- 払う人: 親。ただし無料アプリが多く、課金は難しそう（未確認）
- 強み: すぐ作れる。自分の家で毎日使える（ドッグフーディング）
- 注意: 「次に使ってよい時刻」をアプリが決めない。薬袋や説明書に書いてある間隔を、親が自分で入れる形にする

### 案3: 保育園の与薬依頼書を自動で作る
- 中身: 薬の情報から依頼書を作り、印刷するか園に送る
- 払う人: 親（少額）か、園の連絡帳アプリとの提携
- 強み: 競合が見当たらない（未確認）。困りごとがはっきりしている
- 弱み: 園ごとに様式が違う。利用は「保育園に通っていて、薬が出たとき」に限られる

### 組み合わせ（おすすめ）
案2を、親が無料で使える道具として先に作る。応募用のデモにして、自分の家で毎日使う。
次に、それを薬局が「うちの患者さんに配る」形にして（案1）、お金は薬局から受け取る。
親が自分で使う理由（案2）と、薬局が払う理由（案1）をつなげる。

## 4. 守ること（追加）

- 勤め先の薬局の患者情報、処方内容、社内資料は、リポジトリにもデモにも入れない（BootCamp の規則でも NDA・社外秘は持ち込み不可）。窓口での経験は、個人が特定できない形でだけ使う
- 副業先や本業の就業規則で、自分で事業を始めることに制限がないかを確認する

## 5. 次に確かめること

1. 窓口でよく聞かれる質問の上位5つ（ユーザー本人の経験から。個人が特定できない形で）
2. 薬局は服薬フォローアップを今どうしているか。電話か、ツールか、していないか。ツールの月額はいくらか
3. 親3〜5人に、案2のデモを見せて「今週これがあったら使ったか」を聞く
4. 2024年改定のあとの、小児に関わる調剤報酬の点数と要件（厚労省の原文）

## 6. 窓口の声（2026-10-10、ユーザー本人の経験）

1. 親によく聞かれるのは「薬を混ぜていいか」「アイスと一緒に食べさせていいか」
2. 勤め先の薬局では、服薬フォローアップはあまりできていない
3. 自分の家での困りごとは、これから記録していく

## 7. 「何に混ぜていいか」について分かったこと

- 確認済み: PMDA は一般的な注意として次を案内している（[PMDA くすりQ&A](https://www.pmda.go.jp/safety/consultation-for-patients/on-drugs/qa/0008.html)）
  - 酸性の強い飲食物（オレンジジュース、スポーツドリンク、乳酸菌飲料、ヨーグルトなど）は避ける。コーティングがはがれて苦くなったり、効き目が弱まる薬がある
  - 混ぜたら長く置かず、すぐに飲ませる
  - 熱いものに混ぜない
  - 1歳未満にハチミツは不可
- 確認済み（中身は未確認）: 国立成育医療研究センターが、抗菌薬や解熱薬のドライシロップと食品（ココア、牛乳、アイス、お茶、ヨーグルト、ジュース、乳酸菌飲料、スポーツ飲料）の相性表を公開している。元は 2010年の日経ドラッグインフォメーションの記事。メーカーで味が違うと注記あり（[PDF](https://www.ncchd.go.jp/hospital/about/section/medicine/nomiawase.pdf)。この作業環境からは開けなかった。ユーザーが開いて確認する）
- 確認済み: 薬剤師会の資料でも、苦い薬はチョコアイスやココアなど味の濃いものに、酸味のあるものは苦味が増す、と案内している（[熊本 くすりの話](https://kmh.or.jp/wp/wp-content/uploads/2023/04/okusuri_14.pdf)）
- 確認済み: 飲料と混ぜたときの pH と苦味を測った論文がある（[薬学雑誌 2008](https://yakushi.pharm.or.jp/FULL_TEXT/128_3/pdf/479.pdf)）
- 未確認: 薬ごとに「混ぜてよい食べ物」をスマホで引けるサービスは、検索では見つからなかった
- 注意: 資料の表をそのまま転載すると著作権の問題がある。アプリには出どころへのリンクを付け、薬剤師が確認した内容だけを載せる

## 8. ここから見えた方向（案）

案1と案2をつなぐ形にする。

- 薬局で薬を渡すとき、QR コードか LINE で、その子の薬の「飲ませ方カード」を渡す
  - 混ぜてよい食べ物、苦くなりやすい食べ物（出どころ付き、薬剤師が確認済みのもの）
  - 飲めなかった、吐いたときは薬局に連絡、の導線
- 数日後に「お薬飲めていますか？」が届く。困っていれば薬局に知らせる
- 親にとっては、家で「アイスでいい？」とすぐ分かる。薬局にとっては、電話の問い合わせが減り、できていなかった服薬フォローアップができる。お金は薬局から
