# 親が見て分かりやすい動画（調べたこと）

飲ませ方の動画を見るのは、子どもではなく親（母親）。親が見て分かりやすい動画の作りを調べた（2026-11-17 ユーザー「見るの母親だから、母親がみてわかりやすい動画を調査して」）。子どもに見せる動画の決まりは docs/30。

- 調べたもの: 教える動画の研究、患者向けの資料の物差し、YouTube で親に見られている「粉薬の飲ませ方」の動画
- 手本の動画から学ぶのは、型（長さ、画面の作り、字幕の出し方）だけ。**薬の中身は手本にしない**（ジュースに混ぜるなど、資料で確かめていないやり方が多い）
- ここに書いたことは、まだ「仮の決まり」。親に見せたときの動き（最後まで見るか、同じようにできるか）で直す

見て分かった型:
- 最初の1〜2秒で、だれが何を教えるかを字幕で出す
- 手元を真上か、ななめ上から、画面いっぱいに撮る。背景は机だけ
- 字幕は1行、白い字に黒いふち、画面のまん中。「②スプーンとお皿をからっからにする」のように番号つき
- 「1/3」のような、いくつ中のいくつ目かの印
- 子どもが出るときは、顔をぼかす
- 絵のキャラクターや、作りこんだ動きは、見られている動画には出てこない

## 今の動画とくらべる

| 見る所 | 今の動画（絵＋うさぎの解説） | 紙のコマ撮り風 |
|---|---|---|
| 短く区切る・番号 | ○（1・2・3の丸） | ○ |
| 字幕・音なしで分かる | ○ | ○ |
| 長さ | ○（35〜55秒） | ○（41秒） |
| 手元を、やる人の目線で | △（絵が止まっている。水の量、だんごのかたさは、絵では伝わりにくい） | ×（うさぎを横から見る。手元ではない） |
| 飾りを入れない | △（うさぎの丸い枠、曲） | ×（わざとかくかく動かす、星、部屋、効果音） |
| だれが教えているか | △（うさぎ。薬剤師とは出ていない） | × |

- 紙のコマ撮り風の飲ませ方は、ユーザーが見て「紙がかくかくして、正直微妙」（2026-11-17）。調べたことの 2（飾りを入れない）と同じ向きの感想。**親向けの手順の動画には、この絵柄を使わない**（5秒の試しは「めっちゃいい」だったので、宣伝や子ども向けの短い動画には残す）
- いちばん大きな差は 1（実写の手元）。薬剤師の手で、本物の粉・水・スポイトを撮れば、水の量やだんごのかたさが、そのまま伝わる
