## 2026-11-06 までに分かったこと

- トップのゼロベース案を2回出した（薬袋・分包の2案、ポスター・会話・食べ物の3案）。ユーザーの感想は「あんまり変わらない」「すごく微妙」。Claude だけで見た目を考えても、よくならなかった
- 調べて分かったこと: Claude Code は「作る人」で、「何をいいと思うか決める人（アートディレクター）」ではない。いい見本（参考の画面）、変えない決まり、避けたい見た目を渡し、スクリーンショットで確かめる、を回すとよくなる（superdesign のブログ。外の会社の宣伝の記事なので、考え方の参考にとどめる）

## ほかの上げ方（候補）

1. **好きな見本を集めて渡す**: App Store、Instagram、Pinterest などで「いいな」と思う画面のスクリーンショットを2〜3枚集め、Claude に「これに寄せて」と頼む。無料。基本理念の「何が欲しいかを持つ」と同じ
2. **Claude Design（Anthropic 公式のデザインの道具）**: キャンバスの上で画面を作って直し、Claude Code に引き渡せる
3. **人が描いた絵を入れる**: いらすとや（商用は1つの制作物につき20点までと言われている。使う前に公式の規約で確かめる）か、ココナラなどで、くまのキャラクターを描いてもらう（有料）
4. **人に見てもらう**: BootCamp でデザインが得意な人、または親に5秒見せて感想を聞く
