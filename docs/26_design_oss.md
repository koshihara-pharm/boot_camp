# デザインを上げるためのオープンソース

- 2026-11-05 に GitHub で探した（★の数はその日のもの）。ユーザーの指示「デザインを上げるために、いろいろ試したい」
- 試し方: 1つずつ見比べのページ（Artifact。非公開）で決める → ブランチで試す → スマホで触って決めてから main に入れる（本番は main だけを出している）
- 残すもの: 色、丸い文字、くまの「のめた！」のスタンプ（2026-10-31 ユーザー）
- 画面を変えるときは、いつも ui-check で確かめる（docs/22）
- ライセンスは使う前に確かめる。サイトに入れるときは、ライセンスの文と出どころをリポジトリに残す
