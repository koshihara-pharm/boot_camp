## 使い方の決まり

- 表をそのまま写さない（転載しない）。小児科でよく出る薬 25種類だけを選び、薬ごとのカードという別の形にして使う
- 画面には必ず資料名、改訂日、URL を出す
- 元の画像はリポジトリに入れない
- できれば、資料を作った病院の薬剤部に「アプリで使わせてほしい」と一言連絡する（未）

## 画面での分け方

| 表の記号 | 画面の表示 |
|---|---|
| ○（色つき＝メーカー推奨） | ◎ メーカーのおすすめ |
| ○ | ○ 混ぜてだいじょうぶ |
| ○/×（文献により評価が異なる） | △ 資料によって評価が分かれる（色つきなら「メーカー推奨」の小さな印） |
| × | × 苦く・飲みにくくなりやすい |
| ○/▼、×/▼（吸収などに影響あり） | ！ 効き目に影響することがある（薬剤師に確認） |
| −（データなし） | 折りたたんで「データなし」 |

備考欄は、意味を変えない範囲で親に分かる言葉に直した。

## 飲ませ方のコツ（2026-10-11 追加。`data.js` の HOWTO）

## のめた！スタンプ

- 押すと大きなスタンプ（動物などの絵文字）が出て「のめたね！すごい！」とほめる。「まちがえた（とりけす）」で直前の 1 つを消せる
- 記録（薬の名前、日時、スタンプの絵）は、そのスマホのブラウザの中だけ（localStorage）に保存。サーバーには送らない
- スタンプ帳で、日ごとに見返せる
- 次の候補: 「○日分を最後まで飲みきったらごほうび」、家族に LINE で送る
