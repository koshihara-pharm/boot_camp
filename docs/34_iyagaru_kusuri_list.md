## 読み方

- **判定**
  - A: 嫌がられやすい。複数の資料が、薬の名前を挙げて「苦い」「嫌がる」「飲めない」と書いている
  - B: 条件つき。ふつうは飲めるが、後味・混ぜるもの・溶かして置く・ざらつき・量などで飲みにくくなる
  - C: 資料で分かれる、または資料が弱い（個人の味見のブログだけ、など）
  - D: 飲みやすいとされている
  - E: 資料が見つからない
- **確かめ方**: 「原文」は資料のページを開いて読んだもの。「要約」は道具（WebFetch）が読んで返した要約で、言い回しの細部がずれることがある。「抜粋」は検索の抜粋だけ。**サイトに使う前に、薬剤師が元のページを見る。**
- 資料の文は写さず、自分の言葉で書いた。
- 個人のブログ（薬剤師が自分でなめた感想）は、補いとして使った。それだけが根拠の薬は C にした。

## 先に分かったこと

1. 病院・論文・薬剤師向けの記事が、名前を挙げて「拒否が多い」と書いている薬は多くない。**プレドニゾロン散、クラリス、ジスロマック、タミフル、バナン、メジコン散**が中心。
2. 論文の実験と、現場の声が食い違う薬がある（クラリス、タミフル）。水にといた液をこして大人が味見した実験では「ほとんど苦くない」。現場では「苦い薬の代表」。**水ですぐ飲めば苦くないが、酸っぱいものに混ぜる・置いておく・口に残ると苦い**、と読める。ここがワンポイントの中心になりそう。
3. 嫌がる理由は、苦味だけではない。**ざらつき（酸化マグネシウム、アドソルビン、セレニカR）、塩味（モビコール）、量とにおい（クラバモックス、ワイドシリン）、辛味・酸味（漢方）**がある。
4. **混ぜる組み合わせで苦くなる**: クラリス・ジスロマックと、ムコダイン（カルボシステイン）のドライシロップやタミフルを一緒にとかすと、強く苦くなる（論文に、5歳の子が飲めなかった例がある）。
5. **薬によって、合う食べ物が逆になる**: タミフルはバニラアイスが合わずチョコアイスが合う。バナンは水がいちばん苦く、ジュースが合う。「りんごジュースに混ぜるだけ」でうまくいかない理由の1つ。
6. サイトの今の味と、資料の味がずれている薬がある（下の表の「サイトの味とのずれ」）。

| メジコン散 | チョコアイス、ココア、練乳。1回の量がとても少ないので、一気に飲んで、そのあと甘いもの | m3、薬剤師のブログ |
| バナン | ほかの抗菌薬と逆。オレンジジュース、りんごジュース、スポーツ飲料、ヨーグルト、アイスが合い、水がいちばん苦い（メーカー推奨と書くサイトがある。メーカーの資料は未確認） | ミナカラ、耳鼻科クリニック |

| カロナール | 飲み物にとかさない。アイス、練乳、チョコクリームなど、甘くてとろみのあるものに | ミナカラ、箕面の表 |

## サイトに無いが、何度も名前が出た薬

足すかどうかを考える材料。

- バクタ／バクトラミン顆粒（実験で苦味3超）、トミロン細粒（後味がわずかに苦い）、ビクシリンドライシロップ（神奈川こどもで「苦味あり」）
- アレジオンドライシロップ（甘苦い。販売が終わった製品として、サイトから外してある）
- つくしAM配合散、フェノバルビタール散、リン酸コデイン散、ジメモルファンドライシロップ（個人の味見だけ）
- 漢方: 黄連解毒湯、荊芥連翹湯、温清飲、柴胡清肝湯（坂﨑資料で「大変飲みにくい」）
- デカドロン（エリキシルは苦くて量が多い、という質問サイトの回答。シロップは甘い、というクリニックの記事）

## 気をつけること

- 後発品は、会社ごとに味がちがう。ここの話は、多くが先発品か、特定の会社の製品のもの。
- 「飲みやすい」側の根拠は、個人の味見と添付文書の性状が多い。
- 薬の形を変える（散を錠に、など）、ほかの薬と混ぜる・混ぜない、は医療上の判断にふれる。サイトでは、医師・薬剤師に聞く導線にする（CLAUDE.md「守ること」）。
- 開けなかったページ: 神奈川こどもの別の冊子（nomi.pdf）、日経DI と m3 の会員限定の後半、中外製薬のタミフルの指導箋、バナンのメーカーの資料。
