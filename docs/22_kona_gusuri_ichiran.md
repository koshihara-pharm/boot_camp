# 子どもによく出る粉薬の一覧と、サイトに入っているか（2026-11-03）

世の中の粉薬のうち、サイトがどれだけカバーしているかを見るための一覧。
表で見るときは docs/kona_gusuri_ichiran.html（分け方ごとに、入っている／入っていないを色で分けた）。

- 出どころ: 厚生労働省「薬価基準収載品目リスト及び後発医薬品に関する情報について（令和8年11月1日適用）」の内用薬の Excel（ユーザーが 2026-11-03 にダウンロードして共有） https://www.mhlw.go.jp/topics/2026/04/tp20260401-01.html
- しぼり方: 内用薬のうち、品名に「散」「細粒」「顆粒」「ドライシロップ（DS）」「原末」「微粒」「内用剤」があるもの。錠剤・カプセル・液は除いた
- 数え方: 製品ではなく**成分**で数える（同じ成分にジェネリックが何十もあるため）
- 「子どもによく出る」の選び方: 品名に「ドライシロップ」「DS」「小児用」がある成分（70）を出し、一般の小児科で出ることが少ない専門の薬を外した。そこに、名前に「小児」がなくても子どもによく出る粉薬（漢方、整腸剤など）を足した。**選んだのは Claude。薬剤師（ユーザー）が直す**

## 処方の数で見た順位（2026-11-03。いちばん確かな物差し）

- 出どころ: 厚生労働省「第10回 NDB オープンデータ」内服薬・外来（院外）・性年齢別薬効分類別数量（2023年4月〜2024年3月の処方。ユーザーが 2026-11-03 にダウンロードして共有） https://www.mhlw.go.jp/ndb/opendatasite

### 今のリストに名前が無いもの（販売が終わった可能性）

サイトの名前のうち、次の4つは今回のリストに同じ名前の製品が無かった。成分のほかの製品はある（エピナスチンを除く）。
- アレジオンドライシロップ（エピナスチンの粉薬そのものが無い）
- テオドールドライシロップ（テオドール顆粒、テオフィリン DS はある）
- ムコサールドライシロップ（アンブロキソール DS、小児用ムコソルバン DS はある）
- メプチン顆粒（メプチンドライシロップはある）

docs/18 の 2-1 で「今は売っていない名前は扱わない」とした3つ（アレジオン DS、テオドール DS、メプチン顆粒）と同じ。ムコサール DS は新しく分かった。サイトから外すか、今の製品名に変えるかはユーザーが決める。
