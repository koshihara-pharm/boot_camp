## 個人開発の一般的な目安（根拠は弱い）

- 広告の収入は 1人あたり月に数円程度になりやすい。たくさんの人に使われて初めて意味がある（[pentagon](https://pentagon.tokyo/app/2804/) ほか）
- 毎日使う記録アプリはサブスク（月額）と相性がよい。買い切りは広告を消す、機能を開ける、に向く（[shiftb](https://shiftb.dev/articles/indie-dev-monetization)）
- 子育て系で、使う人が集まらず収益がほぼ 0 円だった失敗例もある（[Zenn](https://zenn.dev/s6lv/articles/0c628f662a4457)）
- ぴよログなどの育児記録アプリの料金は、この調べでは確認できなかった（未確認）

## このアプリで気をつけること

- **毎日は使わない。** 子どもの薬は「病気のときだけ」使う。毎日使うものではないので、月額のサブスクは向きにくい（推測）。買い切りか、使うたびの少額、か、ほかの人に払ってもらう形が合う
- **薬の情報の横に、薬の広告を出さない。** 情報が広告に引っぱられていると思われたら、信頼がなくなる。薬の広告にも法律の決まりがある（医薬品等の広告の規制。詳細は未確認）
- **子どもの処方データを売らない。** データは端末の中だけ（CLAUDE.md の決まり）

## お金の取り方の候補（このアプリ向け）

| 方法 | 中身 | 向き・不向き |
|---|---|---|
| 1. 商品の紹介（アフィリエイト） | 「苦くなる」と出た薬のところで、服薬ゼリー（抗生物質用など）、スポイト、投薬カップを紹介。Amazon や楽天のアソシエイト | 困っているその場で、役立つ物を紹介できる。食品や道具なので、薬の広告とは別。ただし情報と紹介ははっきり分ける |
| 2. 無料＋広告、広告を消す買い切り | 熱はかった？と同じ形。¥300 前後 | 王道。ただしたくさんの人に使われないと金額は小さい。アプリストア版にする必要がある |
| 3. 有料機能（買い切り） | 家族で共有、子ども複数、スタンプの絵柄を増やす、受診のときに見せる記録、保育園の依頼書の下書き | 親が「これは助かる」と思う機能に値段をつける。いくらなら払うかを親に聞いて決める |
| 4. 企業との協力（スポンサー） | 服薬ゼリーのメーカー、子ども用品のメーカーなどが、親に届く場として費用を出す | ムーニーのような形。使う人が増えてから。情報の中立は守る |
| 5. 薬局や薬局チェーンが「うちの患者さんに」配る | 薬局の名前入り版を、薬局が月額で使う。アプリを使うのは親のまま | 薬局が払う形。親向けアプリのまま、お金は薬局から。使う人が増えてから |

## 進め方（案）

1. **今（応募まで）:** 無料の Web 版。お金は取らない。使う人を集め、反応を見る（X で需要のしるしがある。docs/05 の 10）
2. **応募のあと、最初の1か月:** 1 の商品紹介を入れる（すぐできる）。親 3〜5人に「どの機能ならいくら払う？」を聞く
3. **使う人が増えたら:** アプリストア版を出して 2・3。数字を見ながら 4・5 を相談しに行く

## まだ決めていないこと

- アプリストア版（iPhone / Android のアプリ）にするか、Web のままでいくか。広告や買い切りをアプリストアで売るには、アプリストア版が必要
- 有料にする機能と値段
