# 飲ませ方の動画の作り方

飲ませ方（docs/17 の「やりたいこと」3）を、スマホ向けの縦長の短い動画（40秒前後）にするやり方。
2026-11-05〜10 にユーザーと試して決めた。だれが、どのパソコンでも同じ形の動画を作れるように、道具は `tools/douga/` に置いた。

**まだ公開しない**（2026-11-10 ユーザーの判断）。そのため:

- できた動画（`video/*.mp4`）と、作業の絵や音（`tools/douga/work/`）は GitHub に上げない（`.gitignore`）
- サイトの「▶ この飲ませ方を動画で見る」は、手元（localhost）で開いたときだけ出る（index.html の `LOCAL`）。公開しているサイトには出ない

## 決めたこと

| こと | 決めたこと | いつ |
|---|---|---|
| 画面の文 | 音が聞こえなくても分かるように、場面ごとに短い文を下に出す。文はサイトの手順（data.js）を短くしたもの。文字だけの画面も、文字が少なすぎる画面もだめ | 11-05 |
| 作る順番 | 動画にする前に、スライド（場面ごとの絵・文・声の一覧）を作って確かめる | 11-05 |
| 絵 | Codex（ChatGPT の画像づくり）で作る、やさしい水彩画。同じ子が続けて出る。大人は手と腕だけ。絵の中に文字は入れない。1〜3歳は男の子、4歳からは女の子 | 11-07、11-10 |
| 音楽 | 既存の曲は使わず、音を計算で作る自作の曲（著作権の心配がない）。明るいポップ調。オルゴール調は「おかしい」ので外した | 11-07 |
| 読み上げ | yomiscript（読み方を AI が書き、Kokoro が読む。Isamu さんの記事 https://zenn.dev/singularity/articles/yomiscript-kokoro-tts ）。Windows の声（Haruka）は機械っぽいので外した。曲は読み上げの3分の1くらいの大きさ | 11-10 |
| 終わりの画面 | サイトの名前と URL だけ。資料の名前と「医師・薬剤師に相談」は入れない（保存用の画像と同じ決まり） | 11-05 |

## 道具（tools/douga）

| ファイル | すること |
|---|---|
| `prompts/*.txt` | Codex に絵を頼むときの文。番号の順に使う（2〜4 は、1 でできた絵を見本にする） |
| `yomi/*.ys` | 読み上げの読み方（YomiScript）。1つの文に1ファイル |
| `yomi.cjs` | `yomi/*.ys` を、読み上げの音声（`work/*.wav`）にする |
| `cfg/*.json` | 動画1本ごとの場面（どの絵、どの文、どの読み上げ）。名前は `年齢-やり方`（サイトの data.js の名前と同じ） |
| `rec.html` | 絵・文・手順の丸・読み上げ・曲を重ねて動かすページ。曲もここで作る（`music` の部分） |
| `make.cjs` | `rec.html` を Chrome（画面なし）で開いて録画し、`video/名前.mp4` を作る |

## 作り方（1本）

要るもの: Node.js、Chrome、Codex（ChatGPT のアカウントでログインしたもの。Plus で使えた）。yomiscript は、初回にモデル（約350MB）を `~/.cache/yomiscript` に取ってくる。

### 1. 絵を作る（Codex）

`tools/douga/work/` で Codex に `prompts/` の文を渡す。Codex のコマンドが使えないときは、Codex のアプリに同じ文を貼ってもよい（できた絵を `work/` に入れる）。

```bash
mkdir -p tools/douga/work
codex exec --skip-git-repo-check --sandbox workspace-write -C tools/douga/work - < tools/douga/prompts/1_toddler_base.txt
```

- Windows で `codex` が見つからないときは、Codex のアプリについてくる `C:\Users\（名前）\AppData\Local\OpenAI\Codex\bin\（英数字）\codex.exe` を使う。英数字の部分はアプリの更新で変わる
- 絵は毎回少しずつ違うものができる。同じ子にそろえるため、2 からは前の絵を見本にさせている
- 使用量の目安（Plus、5時間の枠）: 7枚で約1%、4枚で1〜2%、8枚で約2%

### 2. 読み上げを作る（yomiscript）

1. 読ませたい文の読み方を `yomi/名前.ys` に書く。書き方は `npx yomiscript instructions` で出る。Claude に「この文を YomiScript にして」と頼めば書ける
2. 音声にする

```bash
node tools/douga/yomi.cjs          # まだ無いものだけ作る
node tools/douga/yomi.cjs s3 fk1   # 読み方を直したものだけ作り直す
```

- Windows では音は鳴らず、ファイルに書き出すだけ（yomiscript が音を鳴らすのは Mac と Linux だけ）。1文に5〜12秒かかる
- 長すぎる文は失敗する（Kokoro は1回に 510 音まで）。2つの文に分ける

### 3. 場面を書く（cfg）

`cfg/名前.json` の `scenes` に、場面を順に書く。今の6本を見本にする。

| 書くこと | 意味 |
|---|---|
| `voice` | その場面の読み上げ（`work/` の wav）。場面の長さは、読み上げの長さ＋1.4秒になる |
| `cap` | 下に出す文。1〜3行。長い行は自動で小さくなるので、小さくなりすぎたら分ける |
| `big: true` | 最初の場面だけ。1行目を小さく、2行目を大きく出す |
| `step` | 上の ①②③ のどれか |
| `imgs` | 絵（`work/` の png の名前）。2つ書くと、途中で切りかわる。`cut` は切りかわる時（場面の長さの割合。0.45 なら半分の少し前） |
| `end: true` と `img` | 最後の場面（サイトの名前と URL） |

### 4. 録画する

```bash
node tools/douga/make.cjs toddler-water
```

- 動画の長さと同じくらい（40秒ほど）かかる。足りない絵や読み上げがあると、先に知らせて止まる
- できたものは `video/toddler-water.mp4`。1本 約14MB

### 5. 手元のサイトで見る

1. `.claude/launch.json` の `site` を動かして、http://localhost:8123 を開く
2. 「おすすめの飲ませ方」→ 年齢 → やり方を開く → 「▶ この飲ませ方を動画で見る」
3. 新しい動画を足したときは、index.html の `VIDEOS` に1行足す。動画を差しかえたら `?v=` の日付を変える（ブラウザが前の動画を覚えているため）

## つまずいたこと（同じ失敗をしないために）

- **録画で開くページの指定を間違え、「音楽だけ」のはずの動画に前の読み上げが入った**（11-07）。→ 録画は `make.cjs` 1つにまとめ、設定ファイルの名前で選ぶようにした。できたら、読み上げの切れ目と曲の拍を数字で確かめる
- **録画しながら曲を作ると、パソコンが重くなり、動画が4秒長くなった**（11-07）。→ 曲は録画の前に1本の音にしてから流す（`rec.html` の `OfflineAudioContext`）
- **Chrome の録画の MP4 は、長さが「0秒」と書かれている**。→ `make.cjs` が長さの欄だけを書きかえる
- **localhost のサーバーが動画の途中から読めず、途中に飛べなかった**（11-06）。→ `.claude/launch.json` のサーバーに、動画の一部だけを返す仕組み（Range）を足した

## 公開する前にやること

- 動画を小さくする（今は1本 約14MB、6本で約84MB）
- iPhone と LINE で再生できるかを確かめる
- 声と絵が正しいかを、薬剤師（ユーザー）が1本ずつ確かめる。とくに、絵の薬の袋が本物らしいか、量（「スプーン1杯もない」など）が絵で正しく見えるか
- 読み上げの音声を公開してよいかを、ライセンスで確かめる（Kokoro と yomiscript は Apache 2.0、日本語の音の高さのモデルは CC BY-SA 4.0）
- 画面の読み上げを使う人のために、字幕のファイル（文だけ）を足すか決める

## 画面の確認（ui-check、2026-11-06）

「▶ この飲ませ方を動画で見る」と、押すと出る動画の画面を確かめた（幅 375px、明るい画面と暗い画面）。

| 観点 | 結果 | 見つかったこと |
|---|---|---|
| 3秒テスト・言葉・一貫性・流れ | ○ | 保存ボタンと同じ控えめな形で、言い方もそろっている。画像と同じ画面に出て、✕・外側・Esc で閉じる |
| 操作の結果 | △ | 閉じると止まる。もう一度開くと、止めたところから続く（最初からにするかはユーザーが決める） |
| 配置 | △ | 控えめなボタンが2つ並ぶ（動画・保存） |
| 誰でも | △ | 文は動画の絵に入っているので、画面の読み上げでは読めない（上の「字幕のファイル」） |
| 操作バー | △ | 止めたときに動画の操作バーが下の文に重なる。気になるなら、文の欄を上げる |
