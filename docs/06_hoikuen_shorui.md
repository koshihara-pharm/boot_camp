# 保育園に出す、薬と病気の書類

- 作成: 2026-10-10
- 目的: 親が保育園とのやりとりでどんな書類を書いているかを知り、アプリや薬局が手伝える部分を探す
- 様式は自治体と園ごとに違う。ここにあるのは例。実際には通っている園と自治体の様式で確かめる

## 与薬のルール（園の例）

- 園が飲ませるのは、医師が処方した薬だけ。市販薬、前の残り、兄弟の薬は受け付けない（[さくらばし保育園](https://www.nichiikids.net/nursery/sakurabashi/item/2024/04/b7d996c7685781370b512072fcde3bb7.pdf)）
- 与薬は原則として親がする。園が代わりにするのは、慢性の病気など限られた場合だけ、という自治体もある（[北本市](https://www.city.kitamoto.lg.jp/material/files/group/24/yoyakuyousiki2.pdf)）
- 「熱が出たら」のような頓服は預からない園がある（[椎名町ちとせ保育園](https://www.chitosek.or.jp/admin/wp-content/uploads/2021/02/与薬について　R2年度版.pdf)）
- 1回分ずつ持たせる、容器に名前を書く、など（[さくらばし保育園](https://www.nichiikids.net/nursery/sakurabashi/item/2024/04/b7d996c7685781370b512072fcde3bb7.pdf)）
- 園は薬を鍵のかかる場所に保管し、複数の保育士で人違いや二重投与を確認する（[厚労省 参考資料](https://www.mhlw.go.jp/stf/shingi/2r9852000000zj6g-att/2r9852000000zjc8.pdf)）

## 気づいたこと（アイデアの材料。まだ確かめていない）

1. **与薬依頼書に書く中身の多くは、薬局が渡す「薬の説明書」に載っている。** 薬の名前、飲ませ方、保管方法など。薬局が依頼書の下書きを作れれば、親は書き写さずに済む
2. **園で飲ませずに済むのが、親にも園にも一番楽。** 1日2回（朝・夕）で済む飲み方にできるか、を医師に相談する道もある。薬剤師として現場でどうしているかを確認する
3. **坐薬やエピペンは医師の書類が必要。** アプリが関わるのは、親が書類をそろえる手順の案内と、期限（書き直しの時期）のお知らせくらい
4. **登園届・意見書は病気のあとに出す。** 「いつから登園できるか」の目安は自治体の様式に書いてある。アプリが自分で判断するのではなく、自治体の様式へ案内する形なら手伝える

## 確かめること

- ユーザーの子どもの園では、薬について何を出しているか（与薬依頼書の様式、頓服の扱い）
- 窓口で「保育園の分どうしたらいい？」と聞かれることはあるか。薬局では今どう対応しているか（昼の分を分ける、依頼書の書き方を教える、など）

## 様式のばらつきと、アプリでの扱い（2026-10-11）

- 様式は自治体・園ごとに違う。公立や認可園は自治体の共通様式（横浜市、北本市、大田区など）を使うことが多く、私立や認可外は園独自の様式もある（こすもす保育園、さくらばし保育園）
- 国（厚労省の参考資料）が示しているのは中身だけ。与薬依頼票には「医師名、薬の種類、内服方法等を具体的に記載」。そのため、どの様式でも書く項目は似ている
- アプリでの扱い（案）
  1. 最初は「書き写し用のメモ」: 薬の名前、1回の量、飲ませる時間、保管方法、処方医・医療機関など、依頼書によく出る項目を登録した薬からまとめて出す。どの園の用紙にも使える
  2. 次に、利用者の多い自治体の共通様式に合わせて、そのまま印刷できる形にする
  3. 将来、園の用紙の写真から、どこに何を書くかを案内する（できるかは未確認）
- 確かめること: ユーザーの子どもの園の様式は、自治体の共通様式か、園独自か
- 韓国・台湾も同じ（2026-10-14 調べた）: 台湾は国の統一の様式はなく、教育部の準則（幼兒教保及照顧服務實施準則 第 11 条）にそって園ごとに「託藥單」を作る。中身はほぼ同じ（子どもの名前、日付、時間、飲ませ方と量、保護者の署名。薬袋と処方の添付。書いていなければ口頭では頼めない）。韓国も国の統一様式は確認できず、保育園アプリ（키즈노트など）の中で形がそろっている。→ どの国も「様式はばらばら、書く項目は共通」。このアプリも「共通の項目で書き写すメモ」を作る今のやり方でよい
  - 出どころ: 台湾 https://w5.nhps.tp.edu.tw/happy/68/up_files/dl/臺北市內湖區南湖國小附設幼兒園託藥辦法113.pdf 、https://www.mdes.tp.edu.tw/uploads/16935309832726LsNc15a.pdf 、韓国 docs/13

## 保育園アプリの与薬依頼の仕様（2026-10-14 調べた）

ユーザーの依頼: 「保育園アプリ、くわしく調査してほしい。どんな仕様になっているのか」。公式ページはこの作業環境から開けなかったので、検索結果（公式ガイドの抜粋、利用者のブログ、紹介サイト）でまとめた。画面の細部は未確認。

### Kidsnote（韓国: 키즈노트 ／ 日本: きっずノート）
- 何か: 保育園・幼稚園と親をつなぐ連絡帳アプリ。韓国ではカカオ系で 2.5 万以上の施設（2015 年前後の記事）。日本では 2015 年に三井情報（MKI）が提供を始めた。導入施設数は紹介サイトで 6.3 万、8.5 万とばらつき（いつの数字か不明、韓国を含むかも不明）
- 機能のメニュー: 連絡帳、お知らせ、アルバム、献立、カレンダー、**投薬依頼書**、お迎え時間届、出席簿など。園が使う機能を選ぶ

**親がすること**
1. 「投薬依頼書」を開く
2. 書く: 投薬する日、症状、薬の種類と量、飲ませる時間、保管方法（韓国の利用者ブログ）。日本版は**処方箋や薬そのものの写真を付けて**送れる（公式サイトの説明）
3. 手書きのサインをして送る（サインがないと園は飲ませられない）
4. 送り方: すぐ送る、一時保存、予約して送る
5. **前に出した依頼書を呼び出せる**（同じ薬を何日も頼むとき楽）

**園がすること**
1. 依頼書の一覧を見る。園長は全員分、先生は自分のクラスの子だけ
2. 飲ませたら「**投薬報告書**」を書く。特記事項は任意。日本版は定型文で送れる
3. 報告書を完了すると、**親に届く**
4. 完了した報告書は消せない。直せるのは特記事項だけで、書いた先生と園長だけが直せる（記録として残すため）
5. パソコンで日付ごとに見て印刷できる。データで保管（韓国では園の評価の書類の電子化として強化）。卒園した子の分も園で見られる

**お金**: 園が払う。日本版は基本プランで月 5,500 円（紹介サイト。最新は未確認）。2015 年の開始時は月 6,000 円から

### 紙の様式との比べ
- 紙: 親が書く欄（薬、量、時間、保管、サイン）＋園が書く欄（受け取った人、飲ませた時間、飲ませた人、確認した人）。神戸市は「施設が用意した依頼票に親が書き、飲ませた内容を施設欄に記録」
- アプリでも流れは同じ: **依頼 → 園が確認 → 飲ませる → 報告が親に届く**。紙では親が報告を見られないことが多いが、アプリでは届く

### このアプリ（親向け）での使い道
保育園アプリは園がお金を払って入れるもので、このアプリ（親が使う）とは役割がちがう。まねできるのは親の側の便利さ:
1. **前の依頼の呼び出し**: すでに「おくすり記録」から書き写しメモを作れる。同じ
2. **薬袋の写真を添える**: 園の用紙に書き写すとき、薬袋の写真を見ながら書ける。写真は端末の中だけに置く（CLAUDE.md の守ること）
3. **「保育園で飲めた」を残す**: アプリの報告にあたるもの。お迎えのときに先生から聞いたら、親が「園で のめた」を押す。夫婦で「昼の分は飲めた？」が分かる（docs/03 の仮説 A）
4. **きっずノートを使っている園なら**、このアプリの書き写しメモの文をそのまま貼れる形にする（未検証。園の設定しだい）
