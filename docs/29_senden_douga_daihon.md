# 宣伝動画（3分）の台本「にがにがに、負けない。」

YouTube と X で、サイト「子どものお薬サポート」を知ってもらうための動画の台本。
2026-11-11 にユーザーと決めた。**動画にする前に、この台本をユーザー（薬剤師）が読んで確かめる**（docs/28 の決まり「動画を作る前に、スライドを作って確かめる」）。

## 決めたこと（2026-11-11 ユーザー）

| こと | 決めたこと |
|---|---|
| 見る人 | 小さな子どもがいる母親 |
| 長さ | 3分くらい |
| 形 | 横長（16:9） |
| お話 | にがにがとの対決。夜、子どもが薬をいやがる → 苦い味の「にがにが」がじゃまをする → はかせとだんごがコツを教える → 飲めた |
| 出るもの | キャラクター4つ（docs/17 の 9）。薬を飲む子どもは、画面に出さず声だけ（うさぎの抱っこひもの子は、ずっと眠っている赤ちゃん。薬を飲むのは上の子） |

## せりふの決まり

- コツは、**サイトに書いてあることだけ**を言う。新しいことは足さない（「守ること」: AI が作った説明をそのまま事実として出さない）
- 薬の名前、病気の名前、量の変更、やめる判断は言わない
- 「どの食べ物に混ぜていいか」は言わず、「薬によってちがうので、サイトで薬の名前を入れる」と案内する
- 音が聞こえなくても分かるように、せりふは画面の下に字幕で出す（docs/28）
- 終わりの画面は、サイトの名前と URL だけ（docs/28）

## 薬剤師（ユーザー）に見てほしいところ

1. **8番と9番**: 「苦くなる」を、にがにがが「出てくる」「強くなる」と言いかえている。言いすぎになっていないか。9番は、もとの文の「効き目が落ちたりすることがあります」を言っていない（苦さの話だけにした）
2. **14番**: 「ものが多いんだ」と言い切っている。もとの文は「多くは〜作られています」
3. **20〜22番**: お薬だんごは、サイトでは0〜1歳と1〜3歳のやり方。動画では年齢を言っていない。言ったほうがよいか
4. **25〜27番**: 食べ物に混ぜる話。「アイスやゼリー」の例は出していない（薬によってちがうため）
5. **34番**: 「薬剤師さんに聞いてみてね」。docs/28 では、終わりの画面に「医師・薬剤師に相談」を入れない決まり。ここでは、画面の文字ではなく、せりふで言っている。入れてよいか
6. **お話の中の「子ども」**: 声だけで出る。年齢は決めていない
7. にがにがは「苦い味」そのもので、薬ではない。「薬が悪者」に見えないか
