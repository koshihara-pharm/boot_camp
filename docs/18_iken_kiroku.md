## 1. 親がサイトを開く場面を想定する（2026-10-18）

- だれから: 田沼さん（参加者兼メンター）
- どこで: Slack（自己紹介への返信）
- 意見の要点:
  - 現場の課題から始まっていて良いテーマ
  - 親がこのサイトを開く場面を想定してみると、機能を決めやすくなる。例: 薬局で薬を受け取ったとき、家で飲ませる準備をしているとき、飲めなかった後
- どう使うか（案）:
  - 3つの場面ごとに「親がその時に知りたいこと」を書き出し、今の5つの機能（飲ませ方のコツ、混ぜていいか、味、記録とメモ、「のめた！」スタンプ）がどの場面で役に立つかを当てはめる
  - 例: 受け取ったとき → 味、混ぜていいか / 準備しているとき → 飲ませ方のコツ、混ぜていいか / 飲めなかった後 → 別の飲ませ方、医師・薬剤師への相談の導線 / 飲めたとき → 「のめた！」スタンプ
  - トップ画面を「今どの場面？」から選べる形にするか検討する（片手で数秒、の決まりに合うか）
  - 知り合いの親に聞くとき（docs/17 の 2-(1)）、どの場面で困ったかも聞く
- 状態: 検討中。3つの場面ごとの整理と、次に足す候補を docs/19 に書いた（2026-10-18）

## 2. 粉の色と、一般名への対応（2026-10-18）

- だれから: 同じ BootCamp の参加者（薬剤師）。名前は書かない
- どこで: Slack
- 意見の要点:
  - プロダクト（公開中のサイト）を見てくれた。協力できることがあれば協力する、とのこと

- どう使うか（案）:

  - 粉の色: どれがどの薬か見分けるのに使う。添付文書の「性状」など出どころのある資料から、製品ごとに入れる
  - 詳しくは docs/19 の「次に足す候補」1 と 3
