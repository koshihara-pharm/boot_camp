## 1. 親がサイトを開く場面を想定する（2026-10-18）

- どう使うか（案）:

## 2. 粉の色と、一般名への対応（2026-10-18）

- だれから: 同じ BootCamp の参加者（薬剤師）。名前は書かない
- どこで: Slack
- 意見の要点:

  - 詳しくは docs/19 の「次に足す候補」1 と 3
- 区分と優先度: 一覧では 2-1（一般名。機能・安全 / 高）と 2-2（粉の色。機能 / 中）に分けた
- 状態: 検討中
