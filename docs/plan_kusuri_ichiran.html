仕組み
準備中の薬は、名前だけの別の表として持つ。味や混ぜ方は持たない

画面の動き

トップ→ 薬の一覧を押す →一覧（#list）→ 見られるを押す →薬の画面（今と同じ）

検索は、今の薬（34）を先に探し、見つからなければ準備中の表を探す。準備中の表は、製品名と成分名の両方で見つかる。「準備中」の薬には、味や混ぜ方を一言も書かない（出どころのある資料で確かめるまで出さない決まりのため）。順位は並べる薬を選ぶのに使うだけで、画面には出さない。

どこを直すか
直すファイルは2つと、記録が2つ。1つずつ作ってスマホで確かめる
  • data.js: 準備中の表を足す（例は下）
  • index.html: 「薬の一覧」のボタン、一覧の画面、準備中の検索結果
  • CLAUDE.md: 決まったことに書く。docs/18: 意見 11-1・11-3 を「反映した」に
// data.js に足す（例）
const PREPARING = [
  { name: "アレロック顆粒・DS", generic: "オロパタジン" },
  { name: "アレグラ DS", generic: "フェキソフェナジン" },
  { name: "クラリチン DS", generic: "ロラタジン" },
  // …処方の上位 30 で、まだ入っていない 12
];

作る順番: ① 準備中の検索結果（いちばん小さい。冨田さんの意見にすぐ答えられる）→ ② 一覧の画面とボタン → ③ 一覧の検索の欄。そのあと、順位の上から薬を1つずつ足す（最初はオロパタジン）。
