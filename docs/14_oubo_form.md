## 4. 取り組みたいプロジェクト

```
■ 作りたいもの
「こどもおくすりサポート」：子どもが少しでも薬を飲めるように、親を手伝うスマホ用の Web サイト（のちにアプリ）。

■ 困りごと
私は小児科の門前薬局で働く薬剤師で、子育て中の親でもあります。窓口で一番よく聞かれるのは「この粉薬、何に混ぜていい？」「アイスと一緒でいい？」「どうしても飲んでくれない」です。混ぜていいかは薬ごとに違い、病院が出している表はありますが、PDF の一覧で、子どもを抱えた親が家でスマホから引ける形になっていません。結果として、親は飲ませるたびに子どもと格闘し、飲めなかった薬が余ります。薬が苦手な子は多いのに、エンジニアや企業がほとんど手をつけていない領域です。

■ いまできていること（Claude Code で作成・公開済み）
1. 薬を選ぶと、味とにおいが出る
2. 家にある12の食べ物（アイス、プリン、ジュースなど）と混ぜていいかを、出どころの資料名・年つきで表示。2つの病院の表で評価が分かれる所は、分かれていると表示
3. 飲ませ方のコツ（練ってほっぺの内側にぬる、服薬ゼリーなど。各項目に出どころ）
4. いま飲んでいる薬を記録し、家族に LINE で送るメモ、保育園の与薬依頼書に書き写すメモを作る
5. 「のめた！」スタンプ。最後まで飲みきったらごほうび

■ 大事にしていること
・医療上の判断はしない。量や中止、薬どうしの飲み合わせは表示せず、医師・薬剤師に聞く導線にする
・混ぜていいかは、出どころのある資料の内容だけを、資料名と日付つきで出す。中身は薬剤師の私が確認する
・子どもの薬の記録は端末の中だけに保存し、サーバーに送らない
・片手で、数秒で済む操作

■ 期間中にやること（毎週の機能追加の候補）
・対応する薬と資料を増やし、複数の病院の表を突き合わせる
・飲ませ方を、絵や短い動画で分かるようにする
・ホーム画面に置ける形、LINE から開ける形にする
・知り合いの親に毎週使ってもらい、「今週困ったこと」を聞いて直す
・個人情報を取らずに使われた数を数え、親に「いくらなら払うか」を聞いて、マネタイズの形を決める

■ なぜ私か
薬の知識（資料の読み方、確認）と、親としての困りごとの両方を持っています。副業で薬局向けのホームページや公式 LINE を Notion・Wraptas・Claude Code で作っていて、作って公開するところまで自分で進められます。私自身、生後1か月の子を育てており、この先の数か月で自分が一番使う人になります。最終発表では「うちではこう使っています」を話します。
```
