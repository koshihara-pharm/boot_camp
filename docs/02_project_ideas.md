## 薬のアプリに近い項目

ヘルスケア / コーチング、介護
- 高齢者の見守り AI（異変検知、家族へ自動連絡、本人への声かけ）
- 難聴の高齢者と家族・スタッフの会話をリアルタイムで文字にする支援
- 日々の発話や行動記録から、その人に合った会話相手になるサービス
- モチベーションをサポートする AI（行動ログ、介入タイミング）

家事 / 暮らし
- 家族カレンダーと家事タスクの分担調整（誰がいつ何をやるかの提案・通知）
- 子どもの学校プリント情報管理ツール（紙の情報を整理する、という点が近い）

パーソナル / ライフハック
- 強力なリマインダー（無視できない、無視させない仕組み）
- 「忘れ物を予言する」朝の AI 秘書
- 位置情報に基づくメモ / 通知（例: 薬局に近づいたら知らせる）

未来テクノロジー
- 農業・医療など、高齢化と人手不足が深刻な業界を改善するサービス
- スタートアップが入ってきていない古い業界を刷新するサービス
