## これは何か

Vibe Coding コース限定のオンライン・インキュベーション。非エンジニアも対象。
各自が自分のプロジェクトを進め、時間帯の合う参加者と「相互サポートグループ」を組む（共同開発ではない）。
ゴールは起業に限らない（社内業務改善、非営利、OSS、個人ツールも可）。

## 募集人数・選考

- 先着で20名程度、審査あり
- 「できる限りしっかり書いたうえで、早めに申し込む」ことが求められている

## 参加条件

- 強い内発的動機（人に言われなくても自分で動く）
- 2026年11月〜翌2〜3月、週16時間以上を確保
- 毎週アウトプット（具体的な機能追加、デモの共有）
- 最初の2ヶ月は、他の参加者へのフィードバックと、進捗共有会での月1回以上の発表が必須
- Slack での非同期・テキスト中心のコミュニケーション
- 開発環境を自力で用意できる、GitHub を操作できる（初歩的な技術サポートはなし）
- 2週間以上 Slack で連絡がないと退出の場合あり

## 応募に必要なもの

- オンラインで確認できる今までの実績
- 作りたいもの
- 成果物の URL を1つ以上（アイデアだけは不可）
  - 公開 GitHub リポジトリ（中身のあるもの）
  - 公開している Web サイトの URL
  - 公開できない GUI ツール等は動作を撮影した動画
- 応募フォームから提出（チームでも1人ずつ）

## 題材についての考え方（審査・発表の軸）

- 自分が本当に使いたいツールを作る（ドッグフーディング）。自分が使わないものは誰も使わない
- 流行り、作りやすさ、儲かりそう、という理由で選ばない
- エンジニアやベンチャーが目をつけていない現場の課題に大きなチャンスがある
- 発表会では「私はこう使っています」を語る

## 持ち込みと公開のルール

- NDA・社外秘・取引先情報の持ち込みは不可
- できる限り汎用的に作り、発表時には公開可能な形にする
- 「自分専用の連携ツール」ではなく「同じことで困っている人なら誰でも使える汎用ツール」を目指す

## 参加後の定例

- 週1のアウトプット（Slack で報告）
- 月1の進捗報告（GitHub 上の Markdown。動作確認できる URL、ゴール、スケジュールと進捗、デモ動画、相談事）
- 「相談事」と「サマリー」は必ず人間が自分で書く

## 費用・権利

- 参加費無料、報酬なし
- クラウドや AI の実費は自己負担（Coding Agent は $100 以上のプラン推奨）
- 作ったものの権利は作成した参加者に帰属
- SS が提供するのは Slack チャンネルとアドバイスのみ
