## 5. 守ること（このテーマで特に）

- 資料に書いてあることだけ。資料の表や文章を写さず、自分の言葉で書いて出どころを示す（CLAUDE.md、docs/07）
- 医療上の判断（量、薬どうしの飲み合わせ、変えてよいか）は書かない。医師・薬剤師に聞く導線にする
- 同じ成分の別の製品の資料（例: サワシリンにワイドシリン、ケフラールにセファクロル細粒、販売終了のメプチン顆粒・テオドール DS）は、そのまま当てはめない。使うかはユーザーが決める
- 「酸っぱいもので苦くなる」は主に抗菌薬の話。資料が無い薬の「×」には入れない
- 中身はすべて薬剤師（ユーザー）が確かめてから出す
- 画面を変えるときは、変える前と後にスキル ui-check で確かめる（CLAUDE.md「画面（UI）の決まり」）
- 出すものは日本語。コミットメッセージ・PR の説明も日本語

## 6. data.js に足すときの形

- 準備中の薬（PREPARING）から消し、DRUGS（名前と味）と FACTS（カード）に足す。名前は今の薬価のリスト（令和8年11月）にある製品名。画面では「DS」ではなく「ドライシロップ」
- FACTS の決まりは data.js のコメントのとおり: 食べ物は8つ（アイスクリーム、プリン、牛乳、お茶、ヨーグルト、りんごジュース、オレンジジュース、スポーツ飲料）を基本に、easy（◎ 混ぜると飲みやすい）／good（○ 混ぜても大丈夫）／avoid（× と理由）。資料が1つだけのときは basis と CHECK_ONE_TABLE、資料の参照は FACT_REFS に足す
- 一般名・後発品の行: generic と genericForm（一般名の名前で売られている後発品の形）。後発品の行は1つ、先発品の行は1つ。漢字の名前には yomi（かたかなの読み）
- index.html の `data.js?v=` の日付を変える（古い data.js をブラウザが使い続けないように）
- 確かめ方: Playwright（`require('playwright')`、chromium）でスマホの幅（390px）で開き、トップの検索・一覧（#list）・薬の画面がエラーなく出るかを見る。前のセッションでは、処方データの製品名で探して出るかも確かめた

## 7. 下調べで分かっている要点（どれも原文で確かめる前）

- 「溶かして飲む」薬（モビコール、エレンタール、ソリタ-T、イーケプラ、アイピーディ）は、◎○× の食べ物の表より、溶かし方を中心にしたカードのほうが合いそう（どう見せるかはユーザーが決める）
- 安全の注意: 幼児用 PL は2歳未満に使わない。テオドール顆粒・セレニカ R は徐放なのでかまない。メラトベルは寝る直前、食後すぐは避ける。デパケン細粒は今は 40% だけ（2025-07 から日医工）。はちみつは1歳未満に使わない
- 食い違い（ユーザーが決める）: ケフラール（乳酸菌飲料・アイス）、サワシリン（ヨーグルト）、幼児用 PL（オレンジジュース）、レベニン散の味（レベニン S 配合散の記載かもしれない）
- 漢方13は、処方ごとの「混ぜてはいけない」の資料がほぼ無い。味はツムラの一部だけ。飲ませ方は漢方全体の話（お湯に溶かす、ココア・アイス）として資料ごとに分けてある

## 8. ユーザーとの進め方

- ユーザーは子育て中の薬剤師で、非エンジニア。スマホで読む。説明は短く、専門用語を避ける
- 1つの薬ごとに下書き → ユーザーが確かめる、を繰り返す（大きくまとめて出さない。CLAUDE.md「最上位の考え」）

## 9. やってみて分かったこと（2026-11-04、ユーザーの Windows の PC のセッション）

- 5つの資料のサイト（帯広厚生病院、飯塚病院、成育、くるみ薬局、PMDA）は、この PC から開けた
- 病院の表とインタビューフォームの PDF は、pdftotext で文字にできない（日本語の文字が取り出せない作り）。表は Claude の Read で PDF をそのまま読むと見える（10ページまで）。長いインタビューフォームは、作業用フォルダに pdfjs-dist を入れて文字にすると読めた

- 1つ目の小児用ムコソルバンドライシロップは、病院の表にもくるみ薬局にも行が無かった。どの病院の表にも、同じ成分の販売終了のムコサールドライシロップの行がある。このあとも「同じ成分の別の製品なら表にある」薬が出てくる見込み（サワシリン、ケフラール、メプチン、テオドール）。使うかどうかの決め方をユーザーが決めると、あとが早くなる
