# 親がサイトを開く場面ごとの整理（2026-10-18）

docs/18 の意見 1（親がサイトを開く場面を想定する）と意見 2（粉の色、一般名への対応）をもとに、3つの場面ごとに「親が知りたいこと」と「今の機能」を並べた。

- 「親が知りたいこと」は、docs/03 の調査と仮説から書いた案。実際の親に聞いて確かめる（docs/03 の聞き取りメモに、場面の質問を足す）
- 決めるときの物差しは CLAUDE.md のとおり「それで子どもが飲むようになるか」
- 医療上の判断（もう一度飲ませていいか、量、別の薬にするか）はアプリでは答えない。医師・薬剤師に聞く導線にする

記号: ◎ 今の機能でできる / △ 一部できる / × まだない

## 場面 1. 薬局で受け取ったとき（家に帰ってすぐも含む）

場面のようす: 薬袋と説明書を手に持っている。子どもを連れていて、待たされた後で疲れている。窓口の薬剤師に聞けるのはこの時だけ。

| 親が知りたいこと | 今の機能 | 状態 |
|---|---|---|
| この薬は何味？ 苦い？ | 薬の名前で探す → 味 | ◎ |
| 家にある何に混ぜていい？ ダメなものは？ | 薬の名前で探す → 混ぜていいかの表 | ◎ |
| 薬袋に書いてある名前で探したい（ジェネリックの名前、一般名） | 探せるのは先発品の名前だけ | × |
| どれがどの薬か見分けたい（「ピンクの粉」「白い粉」） | 粉の色は出していない | × |
| いつまで飲むか、家族に伝えたい | おくすり記録 → 家族に LINE で送る | ◎ |
| 保育園に頼むときの書類に何を書くか | おくすり記録 → 保育園に（書き写すメモ） | ◎ |
| 窓口で薬剤師に何を聞いておけばいいか | なし | × |

## 場面 2. 家で飲ませる準備をしているとき

場面のようす: 子どもを抱えながら片手。数秒で済ませたい。子どもがぐずる前に飲ませたい。

| 親が知りたいこと | 今の機能 | 状態 |
|---|---|---|
| 今ある食べ物で、どれに混ぜればいい？ | 混ぜていいかの表（薬ごと） | ◎ |
| どうやって飲ませる？（少ない量で練る、ほっぺの内側にぬる など） | 飲ませ方のコツ（出どころ付き） | ◎ |
| 前に何で飲めたか | おくすり記録のメモ欄（例: アイスに混ぜたら飲めた） | △ 記録を開かないと見えない。薬の画面には出ない |
| すぐその薬の画面を開きたい（毎回検索したくない） | おくすり記録 →「混ぜ方を見る」ボタン | ◎ |
| やり方を目で見たい | 動画はまだない（期間中にやりたいこと。docs/17） | × |

## 場面 3. 飲めなかった後（嫌がった、吐き出した）

場面のようす: 親が焦っている、落ち込んでいる。「もう一回飲ませていいの？」と迷う。

| 親が知りたいこと | 今の機能 | 状態 |
|---|---|---|
| 次は何を試せばいい？（別の食べ物、別のやり方） | 表とコツはあるが、「飲めなかった」から入る入口がない | △ |
| もう一回飲ませていい？ 吐いた分はどうする？ | アプリでは答えない。薬局・医院に聞く導線もまだない | × |
| 別の形の薬（粉→シロップなど）はある？ | なし。代替薬は「別の形があることと相談の導線まで」（docs/17） | × |
| 薬局に電話するとき何を伝えればいい？ | なし（おくすり記録の内容は使える） | △ |
| うちだけじゃない？（気持ちが軽くなる一言） | なし | × |

## おまけ: 飲めたとき

| 親が知りたいこと | 今の機能 | 状態 |
|---|---|---|
| 子どもをほめたい、続けさせたい | 「のめた！」スタンプ、飲みきったらごほうび | ◎ |
| 何で飲めたかを残したい | メモ欄に手で書く | △ |

## 分かったこと

- 場面 1 と 2 の「何味？」「何に混ぜる？」「どう飲ませる？」は、今の機能でだいたい答えられる
- ただし場面 1 の入口で止まるおそれがある。**薬袋の名前がジェネリック（一般名）だと、検索で見つからず、ほかの機能が全部使えない**（意見 2）
- 場面 3 は入口がない。飲めなかったときが、いちばん「子どもが飲むようになるか」に直結する場面

## 次に足す候補（案。決めるのはユーザー）

順番は「それで子どもが飲むようになるか」と「入口で止まらないか」で考えた。

1. **一般名・ジェネリックの名前でも探せる**（場面 1、意見 2）
   - data.js の各薬に一般名（例: クラリス → クラリスロマイシン）を足し、どちらの名前でも検索できるようにする
   - 注意: 混ぜていいかの表と味は、表に載っている製品（主に先発品）の情報。ジェネリックは味や添加物が違い、混ぜたときの変化も違うことがある。一般名で見つけたときは「○○（先発品）の情報です。ジェネリックは味が違うことがあるので、薬局で確認を」と出すか、ユーザー（薬剤師）が決める
2. **「のめなかった」ボタン**（場面 3）
   - 薬の画面に置き、押すと「表で○のほかの食べ物」「ほかのコツ」を出す
   - 「もう一回飲ませていいか」「吐いた分」は答えず、「薬局・医院に聞いてください」と、聞くときに伝えること（薬の名前、いつ飲ませたか、どのくらい出したか）を出す
3. **粉の色**（場面 1、意見 2）
   - 見分けに使う。兄弟の薬が混ざる困りごと（docs/03 の仮説 E）にも効く
   - 色は添付文書の「性状」など出どころのある資料から、資料名つきで入れる。メーカーで色が違うので、製品ごとに書く
4. 前に飲めた方法を、薬の画面の上に出す（場面 2。おくすり記録のメモを使う）
5. 窓口で薬剤師に聞くことのリスト（場面 1）
