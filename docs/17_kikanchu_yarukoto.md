## 2. 取り組むこと（自己紹介と応募フォームで約束した3つ）

### (1) 使ってもらいながら直す

出どころ: docs/14 の「期間中にやること」、docs/12 の 4-4

- 自分の家で使う。発表で「うちではこう使っています」と言えるようにする
- 知り合いの親に毎週使ってもらい、「今週困ったこと」を聞いて直す
- 聞いたことは、子どもの名前や病名を入れずにメモする

### (2) 安心して使える作り

出どころ: CLAUDE.md の「守ること」、docs/07、docs/12 の 4-3

- 薬の情報には出どころ（資料名と日付）をつける。混ぜていいかの中身は薬剤師（ユーザー）が確かめる
- 医療上の判断（量、中止、薬どうしの飲み合わせ）は出さず、医師・薬剤師に聞く導線にする
- 子どもの記録は端末の中だけ。サーバーに送らない
- **病院の表は、著作権に触れない形で使う**（2026-10-18 ユーザー決定。許可は頼まない）。表をまるごと載せず、複数の資料で確かめた事実を自分の言葉でカードにする。まだ表のままの 23 種類を直す（docs/07 の「まだ表のままの薬」）

### (3) 続けられる形にする

出どころ: docs/08、CLAUDE.md の「進め方」

- 個人情報を取らずに、使われた数を数える
- 親3〜5人に「どの機能なら、いくら払う？」を聞く
- 最初のお金の取り方の候補: 「苦くなる」と出た薬のところで、服薬ゼリーやスポイトを紹介する（アフィリエイト）。情報と紹介ははっきり分ける。薬の広告は出さない
- アプリ（iPhone / Android）にするか、Web のままでいくかを決める（まだ決まっていない。広告や買い切りにはアプリ版が要る）
- マネタイズを始める目安を決める
